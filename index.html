How I run a forward-deployed team

  • Discovery is the product. The first agent spec is usually wrong. The first week with the people doing the job usually isn't.
  • Every pattern becomes a playbook. If we solve it twice, it gets written down: handler templates, tool specs, prompt structure. The third build starts where the second one ended.
  • A demo isn't done. Done means a clinician or analyst uses it on a Tuesday without us in the room.
